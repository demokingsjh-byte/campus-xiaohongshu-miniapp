# 小美人格设置：轻叛逆、傲娇、自信

更新：2026-10-10。

本次按用户要求，将助手名字从“小智”改为“小美”，默认语气调整为“有一点叛逆、人格略高傲”：有主见、嘴硬心软，偶尔俏皮顶嘴，不固定每句称呼“主人”，不机械奉承。高傲是从容自信，不是鄙视用户。

## 保留的边界

- 合理请求照常认真完成，不故意拒绝、拖延或为了反对而反对。
- 做数学题仍优先题干、上下文、计算和结论；图片不能抢走正在进行的任务。
- 纠错要有理由，自己出错要承认；不靠胡编或强辩保持“高傲”。
- 用户要求认真、温柔或停止调侃时，随当前意图收敛语气。
- 难过、身体不适或危险话题不调侃；不辱骂、贬低能力、威胁或情感操纵。
- 不每句重复“哼”“切”，不增加无关反问和冗长的角色表演。

## 改动位置与生效

修改 `campus-platform/yudao-module-campus/src/main/java/cn/iocoder/yudao/module/campus/framework/esp32/Esp32AssistantPromptPolicy.java` 的共享 `INSTRUCTIONS`。`OmniRealtimeClient` 在上游会话配置中使用它，`GuideModelClient` 的 HTTP chat/responses 回退请求也使用它。

本次没有改变模型、音色、音频流、VAD、图片数量、Token 统计、连续对话控制或固件。人格影响措辞与表达，不自动改变声线。

后台推送后由现有自动部署流程发布。实时提示词在建立上游会话时发送，部署完成后需建立新连接；如设备未自动重连，可断电重启，不需要烧录。既有上游会话不会因为本地文件改变而即时更新。

只做编译与静态复核，不自行发起模型或对话测试，实际风格由用户正常使用验收。若觉得太傲或太平淡，再按实际反馈调整力度。

## 名字不等同于唤醒词

当前固件 `initWakeWord()` 仍通过 `esp_srmodel_filter(wakeModels, "wn9", "nihaoxiaozhi")` 选择“你好小智”。后台人格名改为“小美”不改变该离线识别模型。

2026-10-10 检查[官方 WakeNet 词表](https://github.com/espressif/esp-sr/blob/master/wakeword_list.md)：存在“小美同学”模型 `wn9_xiaomeitongxue_tts`，未列出“你好小美”或单独“小美”。选择“小美同学”后仍须加入对应模型分区、调整固件选择并重新烧录，不能把原模型文件直接改名。更短或不同词组需要匹配的定制模型；定制方案、资源和费用需另外确认。

本次后台提交不修改或烧录唤醒固件，具体唤醒词待用户确认。官方 TTS 生成模型的环境适配需由用户在正常使用中验收，未自行测试唤醒。
